╔════════════════════════════════════════════════════════════════════════════╗
║                           DATABASE MODELS                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Member
   ├── user (OneToOne → User)
   ├── first_name, last_name
   ├── email, phone, address
   ├── date_of_birth
   ├── membership_status (active/inactive/visitor)
   ├── date_joined
   └── photo

2. Event
   ├── title, description
   ├── event_type (service/prayer/bible_study/youth/conference/outreach/other)
   ├── start_date, end_date
   ├── location
   ├── image
   └── created_at, updated_at

3. Sermon
   ├── title, preacher
   ├── description
   ├── scripture_reference
   ├── date_preached
   ├── video_url
   ├── audio_file
   ├── thumbnail
   └── created_at

4. Donation
   ├── member (ForeignKey → Member)
   ├── donor_name
   ├── amount
   ├── donation_type (tithe/offering/building_fund/missions/special/other)
   ├── payment_method (cash/mpesa/bank/card)
   ├── transaction_reference
   ├── date
   └── notes

5. Ministry
   ├── name, description
   ├── leader (ForeignKey → Member)
   ├── members (ManyToMany → Member)
   ├── meeting_day, meeting_time
   ├── image
   └── created_at

6. PrayerRequest
   ├── member (ForeignKey → Member)
   ├── name, email
   ├── request
   ├── status (pending/praying/answered)
   └── created_at, updated_at

7. Announcement
   ├── title, content
   ├── priority
   ├── is_active
   ├── created_at
   └── expires_at


╔════════════════════════════════════════════════════════════════════════════╗
║                            API ENDPOINTS                                   ║
╚════════════════════════════════════════════════════════════════════════════╝

Base URL: http://localhost:8000/api/

Members:
  GET    /members/              → List all members
  POST   /members/              → Create member
  GET    /members/{id}/         → Get member details
  PUT    /members/{id}/         → Update member
  DELETE /members/{id}/         → Delete member

Events:
  GET    /events/               → List all events
  GET    /events/upcoming/      → Get upcoming events
  POST   /events/               → Create event
  PUT    /events/{id}/          → Update event
  DELETE /events/{id}/          → Delete event

Sermons:
  GET    /sermons/              → List all sermons
  POST   /sermons/              → Create sermon
  PUT    /sermons/{id}/         → Update sermon
  DELETE /sermons/{id}/         → Delete sermon

Donations:
  GET    /donations/            → List donations
  GET    /donations/statistics/ → Get donation stats
  POST   /donations/            → Create donation

Ministries:
  GET    /ministries/           → List ministries
  POST   /ministries/           → Create ministry
  PUT    /ministries/{id}/      → Update ministry
  DELETE /ministries/{id}/      → Delete ministry

Prayer Requests:
  GET    /prayer-requests/      → List prayer requests
  POST   /prayer-requests/      → Submit request
  PUT    /prayer-requests/{id}/ → Update request

Announcements:
  GET    /announcements/        → List announcements
  GET    /announcements/active/ → Get active announcements
